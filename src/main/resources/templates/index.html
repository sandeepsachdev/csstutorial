Learn CSS the practical way

A hands-on tutorial covering CSS fundamentals, the box model, positioning, flexbox, grid, media queries, mobile-first design, and animations — running on Spring Boot. Every example on this site shows the exact CSS it uses. Copy, paste, tweak.

1. CSS Basics

Selectors, cascade, specificity, colors, units, typography, pseudo-classes, custom properties.

2. Box Model

Margin, border, padding, content. box-sizing, overflow, display.

3. Positioning

static, relative, absolute, fixed, sticky, and z-index.

4. Flexbox

22 live examples: rows, columns, wrap, grow/shrink, holy grail, media object, chat bubbles.

5. CSS Grid

Columns, rows, gap, spanning, template-areas, minmax, auto-fit.

6. Media Queries

Breakpoints, prefers-color-scheme, hover detection, container queries.

7. Mobile CSS

Touch targets, viewports, safe areas, bottom nav, mobile forms, drawer, sticky CTA.

8. Animations

Transitions, transforms, @keyframes, hover effects, respectful motion.
Tip: open this page on your phone, or use your browser's device toolbar (Cmd/Ctrl+Shift+M in DevTools) to follow the mobile lessons. Toggle your OS to dark mode and the whole site flips theme.
