Flexbox

Flexbox lays items out along a single axis (a row or a column) and gives you powerful tools for alignment, distribution, and resizing. Every example below is live — open DevTools and play with the values.

Examples: 1. Row basics 2. Column 3. justify-content 4. align-items 5. gap 6. flex-wrap 7. flex-grow 8. flex-shrink 9. flex-basis 10. order 11. align-self 12. Holy grail 13. Navbar 14. Card row 15. Centering 16. Sticky footer

16. Sticky footer pattern

Make the page a column-flex container, give the main area flex: 1, and the footer always sits at the bottom even when content is short.

html, body { height: 100%; }
body { display: flex; flex-direction: column; }
main { flex: 1; }
