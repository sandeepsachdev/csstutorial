Flexbox

Flexbox lays items out along a single axis (a row or a column) and gives you powerful tools for alignment, distribution, and resizing. Every example below is live and shows the exact CSS it uses.

Examples: 1. Row basics 2. Column 3. justify-content 4. align-items 5. gap 6. flex-wrap 7. flex-grow 8. flex-shrink 9. flex-basis 10. order 11. align-self 12. align-content 13. Holy grail 14. Navbar 15. Card row 16. Centering 17. Sticky footer 18. Media object 19. Stat tiles 20. Chat bubbles 21. Form row 22. Pricing table

17. Sticky footer pattern

Make the page a column-flex container, give the main area flex: 1, and the footer always sits at the bottom even when content is short.

html, body { height: 100%; }

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

main   { flex: 1; }        /* claims all leftover vertical space */
footer { /* stays at the bottom */ }

18. The media object

Image on the left, text on the right — the most common UI pattern on the web.

JD

Jane Doe

Posted this two hours ago. Flexbox makes this pattern trivial.

.media-obj {
  display: flex;
  gap: 1rem;
  align-items: flex-start;
}

.media-obj__img {
  flex: 0 0 48px;      /* fixed size, never grows or shrinks */
  width: 48px; height: 48px;
  border-radius: 50%;
  display: flex; align-items: center; justify-content: center;
  background: #0ea5e9; color: white; font-weight: 700;
}

.media-obj__body { flex: 1; }  /* takes the rest of the row */
