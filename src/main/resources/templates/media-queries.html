Media Queries

Media queries apply CSS only when conditions match — the most common being the viewport width. Resize this page or rotate your phone to see the demos react.

Anatomy of a media query

@media (min-width: 768px) {
  .card { padding: 2rem; }
}

Common breakpoints (mobile-first)

/* base = phones */
@media (min-width: 480px) { /* large phones */ }
@media (min-width: 768px) { /* tablets   */ }
@media (min-width: 1024px) { /* laptops   */ }
@media (min-width: 1440px) { /* desktops  */ }

min-width vs max-width

  • min-width — "from this width and up". Pairs with mobile-first CSS.
  • max-width — "up to this width". Pairs with desktop-first CSS.

Stick to one approach. Most teams pick mobile-first because the base styles work everywhere and you only add complexity on bigger screens.

Other useful queries

/* User prefers dark theme */
@media (prefers-color-scheme: dark) { ... }

/* No fine-pointer device — likely touch */
@media (hover: none) and (pointer: coarse) { ... }

/* Reduced motion preference */
@media (prefers-reduced-motion: reduce) { ... }

/* Landscape orientation */
@media (orientation: landscape) { ... }
