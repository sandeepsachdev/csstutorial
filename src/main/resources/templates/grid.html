CSS Grid

Grid is the two-dimensional layout system — columns and rows at the same time. Where flexbox is best for one-directional content, grid shines for page layouts, galleries, dashboards, and forms.

Examples: 1. Basic grid 2. fr units 3. Fixed + fluid 4. Rows 5. gap 6. Spanning 7. Explicit lines 8. minmax 9. auto-fit 10. Template areas 11. place-items 12. Dashboard 13. Photo gallery 14. Form grid

6. Spanning multiple cells

.grid-span         { display: grid; grid-template-columns: repeat(3, 1fr); gap: 0.5rem; }
.span2             { grid-column: span 2; }         /* takes 2 tracks */
.span-full         { grid-column: 1 / -1; }         /* from first to last line */

7. Placing items by line numbers

a → 1 / 3
b → 3 / 5
c → 1 / -1
.grid-lines { display: grid; grid-template-columns: repeat(4, 1fr); gap: 0.5rem; }

/* grid-column: <start-line> / <end-line> */
.place-a { grid-column: 1 / 3; }   /* covers tracks 1-2 */
.place-b { grid-column: 3 / 5; }   /* covers tracks 3-4 */
.place-c { grid-column: 1 / -1; }  /* full width — -1 means "last line" */

8. minmax() — a floor and a ceiling

1
2
3
.grid-minmax {
  display: grid;
  grid-template-columns: minmax(120px, 1fr) 2fr minmax(80px, 1fr);
  gap: 0.5rem;
}
/* The first column is never smaller than 120px, never bigger than 1fr's share. */

9. Auto-responsive grids — auto-fit + minmax

1
2
3
4
5
6

Resize the window. The grid rewraps itself without a single media query.

.grid-autofit {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
  gap: 1rem;
}
/* auto-fit: fit as many 160px+ columns as will fit, then stretch to 1fr each */
/* auto-fill: same, but keep empty tracks instead of stretching */

10. Named regions — grid-template-areas

header
nav
main
ads
footer
.page-grid {
  display: grid;
  gap: 0.5rem;
  grid-template-columns: 140px 1fr 140px;
  grid-template-areas:
    "head head head"
    "nav  main ads"
    "foot foot foot";
}
.pg-head { grid-area: head; }
.pg-nav  { grid-area: nav;  }
.pg-main { grid-area: main; }
.pg-ads  { grid-area: ads;  }
.pg-foot { grid-area: foot; }

/* On phones, redefine the ASCII layout — items follow automatically */
@media (max-width: 640px) {
  .page-grid {
    grid-template-columns: 1fr;
    grid-template-areas: "head" "nav" "main" "ads" "foot";
  }
}

14. A form as a grid

.form-grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 1rem;
}
.form-grid label { display: flex; flex-direction: column; gap: 0.25rem; }
.form-grid input, .form-grid textarea {
  font-size: 16px; padding: 0.5rem; border: 1px solid #cbd5e1; border-radius: 6px;
}
.form-grid .full { grid-column: 1 / -1; }   /* span both columns */

@media (max-width: 480px) {
  .form-grid { grid-template-columns: 1fr; }
}
