box-sizing: the most important rule you'll ever write

By default width only counts the content. Switch to border-box so padding and border are included.

content-box (default)

200px width + 20px padding + 4px border = 248px total.

border-box

200px width includes the padding and border. 200px total.

/* Apply once at the top of your stylesheet */
*, *::before, *::after { box-sizing: border-box; }

Margin collapsing

Vertical margins between block siblings collapse to the larger of the two — a quirk that surprises everyone the first time.

I have margin-bottom: 40px

I have margin-top: 30px

The gap is 40px, not 70px.
