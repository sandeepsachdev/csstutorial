The Box Model

Every element is a rectangle made of four layers: content, padding, border, margin. Understanding how they combine — and how to control that combination with box-sizing, overflow, and display — is the foundation of CSS layout.

On this page: 1. Visualized 2. box-sizing 3. Margin collapse 4. Overflow 5. Display types 6. aspect-ratio

  margin: 1.5rem;

2. box-sizing — the most important rule you'll ever write

By default width only counts the content. Switch to border-box so padding and border are included in the width.

content-box (default)

200px width + 20px padding + 4px border = 248px total.

border-box

200px width includes the padding and border. 200px total.

/* Apply once at the top of your stylesheet — every modern reset does this */
*, *::before, *::after { box-sizing: border-box; }

/* Compare */
.content-box { box-sizing: content-box; width: 200px; padding: 20px; border: 4px; }
/* actual rendered width = 200 + 40 + 8 = 248px  */

.border-box  { box-sizing: border-box;  width: 200px; padding: 20px; border: 4px; }
/* actual rendered width = 200px, content shrinks to 152px */

3. Margin collapsing

Vertical margins between block siblings collapse to the larger of the two — a quirk that surprises everyone the first time.

I have margin-bottom: 40px

I have margin-top: 30px

The gap is 40px, not 70px.

.collapse-demo p:nth-child(1) { margin-bottom: 40px; }
.collapse-demo p:nth-child(2) { margin-top: 30px; }
/* Actual gap between them = max(40, 30) = 40px */

/* Common ways to defeat margin collapse: */
.parent {
  display: flex;         /* flex & grid children don't collapse */
  /* or */ padding: 1px; /* any padding on the parent            */
  /* or */ overflow: auto;
}

4. overflow — what to do with content that doesn't fit

overflow: visible (default). Content spills.

overflow: hidden. Overflow is clipped away.

overflow: scroll. Scrollbars always shown.

overflow: auto. Scrollbars appear only when needed. Lorem ipsum dolor sit amet consectetur adipiscing elit sed do eiusmod tempor incididunt ut labore.

.of-visible { overflow: visible; } /* default: content escapes the box */
.of-hidden  { overflow: hidden;  } /* clip; no scroll                  */
.of-scroll  { overflow: scroll;  } /* always show scrollbars           */
.of-auto    { overflow: auto;    } /* scroll only when necessary       */

/* Axis-specific */
.hscroll { overflow-x: auto; overflow-y: hidden; }

/* Nice-to-know: smooth momentum scrolling on iOS is now default */
.scroll-y { overscroll-behavior: contain; } /* stops scroll chaining to page */

5. display — block, inline, inline-block, none

display: block (fills the line) inline-ainline-binline-c inline-block A inline-block B You can't see me 
.d-block {
  display: block;        /* takes the full line, respects width/height     */
  background: #bae6fd;
  width: 100%;
}

.d-inline {
  display: inline;       /* flows with text, ignores width/height          */
  background: #fef3c7;
  padding: 0 0.25rem;
}

.d-inlineblock {
  display: inline-block; /* flows inline BUT respects width/height/margin  */
  background: #bbf7d0;
  width: 120px;
  height: 40px;
}

.d-none {
  display: none;         /* removed from layout entirely                   */
}
/* Contrast with visibility: hidden — invisible but still takes space */

6. aspect-ratio — lock the shape

16 / 9
1 / 1
3 / 4
/* Set only the width — height follows the ratio. */
.ar-16-9 { aspect-ratio: 16 / 9; width: 100%; }
.ar-1-1  { aspect-ratio: 1;      width: 100%; }
.ar-3-4  { aspect-ratio: 3 / 4;  width: 100%; }

/* Perfect for hero images or embeds without the old padding-bottom hack. */
img, video { aspect-ratio: 16 / 9; object-fit: cover; }
