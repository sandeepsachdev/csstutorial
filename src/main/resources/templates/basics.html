CSS Basics

CSS (Cascading Style Sheets) describes how HTML elements are displayed.

1. Selectors

A selector picks the elements you want to style. The three most common kinds:

/* Type selector */
p { color: #333; }

/* Class selector */
.callout { background: lightyellow; }

/* ID selector */
#main-title { font-size: 2rem; }

2. The cascade & specificity

When two rules target the same element, the more specific one wins. Roughly: inline > id > class > type.

I'm styled by three rules — the ID wins.

3. Colors & units

  • #ff6600, rgb(255 102 0), hsl(24 100% 50%) — color formats
  • px — absolute pixels
  • rem — relative to the root font size (best for typography)
  • em — relative to the parent's font size
  • %, vw, vh — relative to the container or viewport
