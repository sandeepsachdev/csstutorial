CSS Basics

CSS (Cascading Style Sheets) describes how HTML elements are displayed. This page covers everything you need before diving into layout.

On this page: 1. Selectors 2. Combinators 3. Pseudo-classes 4. Pseudo-elements 5. Attribute selectors 6. Cascade & specificity 7. Colors 8. Units 9. Typography 10. Custom properties 11. Backgrounds & borders

1. Selectors

A selector picks the elements you want to style.

Type selector — styled by p

Class selector — styled by .sel-class

ID selector — styled by #sel-id

/* Type — every <p> */
p { color: #333; }

/* Class — any element with class="sel-class" */
.sel-class { background: #fef3c7; padding: 0.25rem 0.5rem; }

/* ID — the one element with id="sel-id" */
#sel-id { color: rebeccapurple; font-weight: 700; }

/* Universal, grouped, chained */
* { box-sizing: border-box; }              /* every element */
h1, h2, h3 { font-family: Georgia; }       /* grouped list  */
button.primary { background: #0ea5e9; }    /* class chained to type */

2. Combinators — relationships between elements

Parent

Direct child <p>

Descendant <p> (nested)

Sibling that follows the parent

Another sibling

/* Descendant — any <p> anywhere inside .parent */
.parent p { color: #0369a1; }

/* Child (>) — only direct children */
.parent > p { font-weight: 700; }

/* Adjacent sibling (+) — the very next sibling */
.parent + p { background: #fef9c3; }

/* General sibling (~) — every following sibling */
.parent ~ p { border-left: 3px solid #0ea5e9; padding-left: 0.5rem; }

3. Pseudo-classes — state-based styling

  • First (:first-child)
  • Middle
  • Middle
  • Last (:last-child)
/* Interactive states */
.pseudo-btn:hover  { background: #0369a1; }
.pseudo-btn:active { transform: translateY(1px); }
.pseudo-btn:focus-visible { outline: 3px solid #f59e0b; }

/* Structural */
.pseudo-list li:first-child { color: #22c55e; font-weight: 700; }
.pseudo-list li:last-child  { color: #ef4444; font-weight: 700; }
.pseudo-list li:nth-child(odd) { background: #f1f5f9; }

/* Form */
.pseudo-input:focus   { border-color: #0ea5e9; }
.pseudo-input:invalid { border-color: #ef4444; }
.pseudo-input:placeholder-shown { font-style: italic; }

4. Pseudo-elements — style parts that aren't real elements

Simplicity is the ultimate sophistication.

The first letter of this paragraph is huge because of ::first-letter.

Requires a checkmark bullet

/* ::before and ::after insert generated content */
.quote::before { content: "\201C"; font-size: 2rem; color: #0ea5e9; }
.quote::after  { content: "\201D"; font-size: 2rem; color: #0ea5e9; }

/* ::first-letter targets the initial letter */
.first-letter::first-letter {
  font-size: 3rem;
  float: left;
  padding-right: 0.25rem;
  color: #6366f1;
  font-weight: 700;
}

/* ::selection styles highlighted text */
::selection { background: #fde68a; color: #78350f; }

/* ::marker styles list bullets */
.marker-demo::before {
  content: "\2713  ";
  color: #22c55e;
  font-weight: 700;
}

5. Attribute selectors

External link Internal link Email link 
/* Exact match */
a[href="/basics"]        { font-weight: 700; }

/* Starts with (^=) — great for protocol matching */
a[href^="mailto:"]::before { content: "\2709 "; }
a[href^="https://"]::after { content: " \2197"; color: #6b7280; }

/* Ends with ($=) */
a[href$=".pdf"]::after   { content: " (pdf)"; }

/* Contains substring (*=) */
a[href*="example.com"]   { color: #a855f7; }

/* Attribute presence */
input[required]          { border-left: 3px solid #ef4444; }
input[type="password"]   { letter-spacing: 0.2em; }

6. The cascade & specificity

When two rules target the same element, the more specific one wins. Rough order: inline > id > class/attr/pseudo-class > type.

I'm targeted by three rules — the ID wins.

p              { color: red;          }  /* specificity 0,0,0,1 */
.cascade-demo  { color: green;        }  /* specificity 0,0,1,0 */
#cascade-id    { color: rebeccapurple;}  /* specificity 0,1,0,0 — wins */

/* !important overrides normal rules (use sparingly) */
p.cascade-demo { color: black !important; }

/* Inline > everything except !important */
<p style="color: orange">…</p>

8. Units

120px
8rem
6em
25%
15vw
/* Absolute */
.px  { width: 120px; }

/* Relative to root font size (the safest for typography) */
.rem { width: 8rem; }   /* 8 × root font-size */

/* Relative to the parent's font size */
.em  { width: 6em; }

/* Relative to the container / viewport */
.pct { width: 25%; }
.vw  { width: 15vw; }   /* 15% of viewport width  */
.vh  { height: 100vh; } /* 100% of viewport height */
.dvh { height: 100dvh; }/* dynamic — accounts for mobile URL bar */

/* Newer, best of both: clamp between a min and max */
h1 { font-size: clamp(1.5rem, 4vw + 1rem, 3rem); }

10. Custom properties (CSS variables)

/* Declare on :root so they cascade everywhere */
:root {
  --brand:   #0ea5e9;
  --danger:  #ef4444;
  --success: #22c55e;
  --radius:  6px;
  --space:   0.75rem;
}

.var-btn {
  background: var(--brand);
  color: white;
  padding: var(--space) calc(var(--space) * 2);
  border: none;
  border-radius: var(--radius);
}

/* Override for variants — reassign the variable, not each property */
.var-btn.danger  { background: var(--danger);  }
.var-btn.success { background: var(--success); }
