CSS Positioning

The position property controls how an element is placed relative to the document, its container, or the viewport. There are five values you use every day: static, relative, absolute, fixed, and sticky.

On this page: 1. static 2. relative 3. absolute 4. Badge overlay 5. fixed 6. sticky 7. z-index 8. Perfect centering 9. Tooltip 10. Modal & scrim

1. position: static — the default

static

I sit right after the box, in normal flow.

.pos-static {
  position: static;    /* default — top/left/z-index have no effect */
}

2. position: relative — nudge without leaving flow

relative
top: 15px
left: 30px

The next element ignores my nudge — my slot in the flow is preserved.

.pos-relative {
  position: relative;
  top:  15px;
  left: 30px;
}
/* Also crucial: makes THIS element a positioning parent for
   any absolutely-positioned descendants. */

5. position: fixed — pinned to the viewport

The site header at the top of this page is almost fixed — it uses sticky, which is nicer. But a true FAB (floating action button) uses fixed. Look at the bottom-right corner:

.fab {
  position: fixed;
  bottom: calc(1rem + env(safe-area-inset-bottom));
  right:  calc(1rem + env(safe-area-inset-right));
  width: 56px; height: 56px;
  border-radius: 50%;
  background: #0ea5e9; color: white;
  box-shadow: 0 6px 20px rgba(14, 165, 233, 0.4);
  z-index: 50;
}
/* Stays put when the page scrolls. Independent of any parent's overflow. */

7. z-index — stacking order

z-index: 1
z-index: 3
z-index: 2
.zbox { position: absolute; width: 100px; height: 100px; }
.z1 { z-index: 1; background: #ef4444; top:  0;    left:  0;   }
.z2 { z-index: 3; background: #22c55e; top: 30px;  left: 60px; }
.z3 { z-index: 2; background: #0ea5e9; top: 60px;  left:120px; }

/* Rules to remember:
   - z-index only works on positioned elements (not static).
   - It applies within a "stacking context". A parent with opacity < 1,
     transform, filter, or z-index creates one — children of different
     contexts can't interleave.  */

8. Three ways to center absolutely

/* Classic: percent offset + transform */
.center-a {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}

/* Modern: inset shorthand + margin auto */
.center-b {
  position: absolute;
  inset: 0;
  margin: auto;
  width: 200px; height: 100px;
}

/* Best: don't position at all — use flex/grid on the parent */
.parent { display: grid; place-items: center; }

9. A pure-CSS tooltip

Hover the button below on desktop, or long-press on touch.

.tip-btn { position: relative; }

.tip-btn::after {
  content: attr(data-tip);      /* pull the label from the HTML attribute */
  position: absolute;
  bottom: calc(100% + 8px);     /* sit 8px above the button              */
  left: 50%;
  transform: translateX(-50%);
  background: #111827; color: white;
  padding: 0.4rem 0.6rem;
  border-radius: 6px;
  white-space: nowrap;
  font-size: 0.8rem;
  opacity: 0;
  transition: opacity 0.15s ease;
  pointer-events: none;
}

.tip-btn:hover::after,
.tip-btn:focus-visible::after { opacity: 1; }

10. Modal & scrim (no JavaScript)

Click below — the checkbox drives the state.

A CSS-only modal

The scrim is a fixed layer under the modal; the modal is centered with flex.

.modal-toggle { display: none; }

.modal-scrim {
  position: fixed; inset: 0;
  background: rgba(0,0,0,0.5);
  opacity: 0; pointer-events: none;
  transition: opacity 0.2s ease;
  z-index: 40;
}

.modal {
  position: fixed; inset: 0;
  margin: auto;
  width: min(90vw, 400px); height: fit-content;
  padding: 1.5rem;
  background: white; border-radius: 12px;
  box-shadow: 0 20px 60px rgba(0,0,0,0.25);
  opacity: 0; transform: scale(0.95); pointer-events: none;
  transition: opacity 0.2s ease, transform 0.2s ease;
  z-index: 50;
}

.modal-toggle:checked ~ .modal-scrim,
.modal-toggle:checked ~ .modal {
  opacity: 1;
  pointer-events: auto;
}
.modal-toggle:checked ~ .modal { transform: scale(1); }
