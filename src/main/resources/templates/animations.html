Transitions & Animations

Add motion tastefully. Transitions animate between two states — usually on hover or focus. @keyframes animations run on their own timeline. Always respect prefers-reduced-motion.

On this page: 1. Transition basics 2. transition shorthand 3. Multiple properties 4. Timing functions 5. transform 6. Hover effects 7. @keyframes 8. Spinner 9. Bounce 10. Skeleton loader 11. Reveal on scroll 12. Reduced motion

1. Transition basics — animate a change of value

Hover me
.t-basic {
  background: #0ea5e9;
  transition: background 0.3s;   /* animate background changes over 0.3s */
}
.t-basic:hover { background: #ef4444; }
/* Without the transition line, the color would snap instantly. */

2. transition shorthand

.button {
  /* property   duration  timing-function  delay */
  transition: transform  0.2s      ease-out         0s;
}

/* Longhand equivalent */
.button {
  transition-property:        transform;
  transition-duration:        0.2s;
  transition-timing-function: ease-out;
  transition-delay:           0s;
}

3. Animating multiple properties

.t-multi {
  background: #0ea5e9; color: white;
  padding: 0.5rem 1rem;
  border-radius: 6px;

  /* Comma-separate to give each property its own timing */
  transition:
    background 0.2s ease,
    transform  0.2s ease-out,
    box-shadow 0.3s ease;
}

.t-multi:hover {
  background: #0369a1;
  transform: translateY(-2px);
  box-shadow: 0 6px 16px rgba(3, 105, 161, 0.35);
}

5. transform — cheap, GPU-accelerated motion

translate
rotate
scale
skew
.tf.translate:hover { transform: translate(20px, -10px); }
.tf.rotate:hover    { transform: rotate(15deg); }
.tf.scale:hover     { transform: scale(1.2); }
.tf.skew:hover      { transform: skew(10deg, 0); }

/* Combine — order matters (applied right-to-left) */
.tf.combo:hover { transform: translateY(-4px) scale(1.05) rotate(-2deg); }

/* Always transition transform (and opacity). Avoid animating layout
   properties like width/height/top/left — they trigger reflow. */
.tf { transition: transform 0.2s ease-out; }

7. @keyframes — animations on their own timeline

Fades in
@keyframes pulse {
  0%   { transform: scale(1);   opacity: 1;   }
  50%  { transform: scale(1.4); opacity: 0.5; }
  100% { transform: scale(1);   opacity: 1;   }
}

.pulse {
  width: 40px; height: 40px;
  background: #0ea5e9; border-radius: 50%;
  animation: pulse 1.5s ease-in-out infinite;
}

@keyframes fadeIn {
  from { opacity: 0; transform: translateY(6px); }
  to   { opacity: 1; transform: translateY(0);  }
}
.fade-in { animation: fadeIn 0.6s ease-out both; }

/* Shorthand: name duration timing delay iteration-count direction fill-mode */
.item { animation: fadeIn 0.5s ease-out 0.2s 1 normal both; }

11. Reveal on scroll (no JavaScript)

Modern CSS can animate as elements enter the viewport using animation-timeline: view(). Currently in Chromium — with Firefox & Safari picking it up.

@keyframes reveal {
  from { opacity: 0; transform: translateY(24px); }
  to   { opacity: 1; transform: translateY(0);    }
}

.card {
  animation: reveal linear both;
  animation-timeline: view();               /* drive it by scroll position    */
  animation-range: entry 20% cover 40%;     /* between these viewport ranges  */
}

/* Fallback for browsers without scroll timelines */
@supports not (animation-timeline: view()) {
  .card { animation: reveal 0.5s ease-out both; }
}

12. Respect prefers-reduced-motion

/* Anyone who has "Reduce motion" enabled gets a calmer experience */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.001ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.001ms !important;
    scroll-behavior: auto !important;
  }
}
/* This app already applies this rule globally in mobile.css. */
